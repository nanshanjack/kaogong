行测统一判定法

从 300 道正确率 50–60% 的真题里，归纳同一套动作：把题干翻译成条件，在四个选项里选唯一满足全部条件的选项。

取样 2026-11-07 6 模块 × 50 题 = 300 正确率 50–60% 近 5 年 · 不限地区 未作答 · 未提交 · 未写入错题本 字段完整 300/300 依据：官方大纲 + 公文条例/国标 + 样本验证 图推 20 题逐题走链

行测不是“猜出题人想考什么”，而是“题干给条件，选项里只有一个解”。

把每道题看成一个小型条件系统：题干给出显性条件与隐含条件，四个选项是四个候选解。正确答案是同时满足全部条件的那一个；错误选项不是随机干扰，而是每一个都精准违反一个条件。

所以，做题的动作不是“找感觉”，而是：定问法 → 抽条件 → 逐项验 → 锁唯一 → 时间止损。六模块的差别，只在于“条件从哪里来”。

铁律一

先定问法，再找条件。问“错误/不能推出”时，目标就是找违反条件的那一项。

铁律二

每个选项都要验条件，不能凭“顺眼”选。说不清它满足了哪条，就先不选。

铁律三

两个选项都像对，说明你漏了一个条件。回题干找区分点，而不是硬猜。

01 · 五步判定链

所有模块共用；不同模块只是“抽条件”的对象不同。

  1. 定目标

    先看问法：选正确、选错误、选最恰当、选能推出、选有几项。问法决定你要找“满足条件”还是“违反条件”的选项。

    动作：圈出问法里的关键词，别急着读选项。
  2. 抽条件

    把题干翻译成 2–4 条可检验的条件：语义关系、搭配、主题词；规律、定义四槽、论证桥；方程、公式、数据；法条、原理、原文。

    动作：在心里写 C1/C2/C3，写不出条件就先别选。
  3. 逐项验

    每个选项都过一遍条件：满足全部 → 候选；违反任意一条 → 排除。不要只验证你觉得“像”的那一项。

    动作：排除时说出“它违反了哪条”，而不是“它不对”。
  4. 锁唯一

    候选只能剩一个（指在四个选项范围内唯一）。若剩两个，说明条件漏了：回题干找区分点（程度、范围、主体、时间、例外）。

    动作：两个都像对时，问“哪一个条件我还没用上？”
  5. 止损

    超过该模块的单题上限仍闭不上条件，标记跳过；最后用排除到 2 选 1 再猜，不空题。

    动作：平时就按上限计时，考场上才敢跳。

条件卡：一道题长什么样

以言语逻辑填空为例，题干条件可以写成：

C1 语义
空格与“消极懈怠”构成并列 → 必须含“停滞不前”义
C2 搭配
空格 + “泥潭” → 搭配要能落地
C3 程度
不能过重，不能带“自我放弃”
判定
A 过轻 / B 全过 / C 全过但第二空不符 / D 色彩不符 → 锁 B

这就是“像学语法一样”：不是背题，而是看每个空要满足的语法槽位。

02.5 · 证据与边界

规则不靠“名师说了算”，按三层证据处理：官方大纲定范围，官方公文/高校课程/开源资料给候选，300 题样本做验证。

① 范围层

官方大纲/公告：模块、时限、能力要求。

解决“考什么”，不解决“怎么解”。

② 规则层

公文条例/国标、高校课程、开源仓库与公开文章：提供可检验的规则候选。

每条规则必须写清适用条件与反例。

③ 验证层

300 题样本 + 粉笔错题：逐条对照，支持/反例/边界。

有支持且无反例，才进入方法页。

03 · 言语理解与表达：三关交集

50 题样本：逻辑填空 24，片段阅读/语句表达 26。

MODULE 01言语：正确答案是“语义 + 搭配 + 程度”的交集50 题 · 答案 B17/D14/C9/A10

这个模块的条件是什么

逻辑填空的条件来自空格前后：并列/反义/解释/递进/转折；搭配对象；程度与感情色彩。片段阅读的条件来自文段结构：主题词、行文脉络、问法。语句填空的条件来自横线位置：承上、启下，或两者同时。

四条不变量

  1. 逻辑填空三关：语义关系、搭配、程度。三个都过才是答案；只过两关的选项，就是“近义陷阱”。
  2. 片段阅读主题词：正确答案必须覆盖文段核心话题；缺主题词、偷换主体、只谈非重点的选项，一律排除。
  3. 语句填空看位置：横线在中间，必须同时承接前文、引出后文；只顺承一侧的，必错。
  4. 错误项四件套：无中生有、搭配不当、程度过重/过轻、主题词缺失。先拿这四把刀切，再谈“语感”。
50/50 解析出现“排除”52% 明确“对应”24% 明确“搭配”32% 提到“无中生有”

把公文的“目的—对象—结构—语言”借到言语/片段阅读；只借这四维，不借 15 文种/格式。

  • 近义成语只差程度：如“安于现状/固步自封/裹足不前”，要看空格前的“消极懈怠”与后文“观望等待”落在哪一档。

04 · 判断推理：规律、四槽、论证桥

50 题样本：图推 20，论证 13，类比 7，定义 2，其他 8（考点可多选）。

MODULE 02判断：先定“形式”，再验“条件”50 题 · 答案 A12/B14/C12/D12

这个模块的条件是什么

图推的条件是图形元素的变换规律；定义的条件是“主体 + 条件 + 方式 + 结果”四个槽位；论证的条件是“论据 → 论点”的桥；类比的条件是两侧词项的二元关系；翻译推理的条件是命题形式。

五条不变量

  1. 图推先看组成，再定顺序：元素组成相同 → 看位置（平移/旋转/翻转）；元素组成不同 → 属性（对称/曲直/开闭）→ 数量（点线面素）→ 样式（加减同异/黑白）→ 特殊（平面拼合/空间重构）。不要死记一个绝对顺序，把它当分层排除；看到一个规律后，继续找第二个，正确答案要同时满足。
  2. 定义拆四槽：主体、条件、方式、结果。四槽全中才是答案；常见错法是偷换主体、漏一个条件、把“水平”换成“结构”。
  3. 论证打桥：先写“论据 → 论点”的桥；削弱/加强必须打在桥上。话题不一致的选项，再正确也不能选。
  4. 类比同向：先定两侧的二元关系，再要求关系方向一致；顺序颠倒、关系不同即错。
  5. 选非题反着验：问“最不能支持/没有体现”时，先排除能支持/能体现的，再在剩下项里选。
66% 解析出现“排除”58% 先找论点/定义关键词图推 20 题 · 论证 13 题

论证例 · 3_1_c941h · 2025 广东 · 第63题 · 正确率 53.04 桥：论据“泡沫最多” → 论点“除菌更好”，中间假设“泡沫 = 有害残留”。D 说专业化学检测才是唯一有效手段，直接切断桥；A 只是削弱泡沫与残留的关系，力度弱于 D → D。

高频陷阱

  • 图推“规律叠加”：只看到一个规律就选，忽略第二个规律（如数量 + 奇偶）。
  • 定义“主体偷换”：主体从企业换成个人、从行政换成民事，直接排除。
  • 论证“话题漂移”：选项讨论死亡率，论点讨论发病率；说得再对也不选。
  • 类比“顺序颠倒”：主宾关系前后反了，关系再像也不选。
时间：图推 45–60s · 定义 60–75s · 类比 30–40s · 逻辑 70–90s

统一判定顺序（最终版，合并“先看组成”与“属性→位置→样式→数量→特殊”）

第一步永远看元素组成：

  1. 组成相同 → 位置（平移/旋转/翻转）→ 图形间连接方式。
  2. 组成相似（有重复元素/线条叠合）→ 样式（遍历 → 加减同异，常配旋转）。
  3. 组成不同 → 属性（对称/曲直/开闭）→ 数量（素/线/点/角/面）→ 特殊（拼合/黑白块）。
  4. 题干形式直接触发空间类：给展开图 → 空间重构；给视图 → 三视图；凹凸补块 → 立体拼合。

05 · 数量关系：等量关系的唯一解

50 题样本：和差倍比 10，几何 8，经济 3，概率 3，排列组合 3，数列 3，行程 3，最值 2（考点可多选）。

MODULE 03数量：把每个条件写进方程，答案自己会出来50 题 · 答案 B18/C18/A9/D5

这个模块的条件是什么

题干里的比例、倍数、和差、增减、时间、速度、价格、浓度、几何关系，都是等量或不等关系。把这些关系写成方程/不等式，解就是答案。

四条不变量

  1. 正确答案是唯一解：方程/不等式解出什么，就选什么；选项只是解的容器。
  2. 每个条件都要进方程：漏一个条件，就会精准落到某个错误选项。错误选项通常对应“漏条件/用错基数/算错一步”。
  3. 极值题先定方向：问“至少”就让目标量尽量小，问“最多”就尽量大；再用不等式边界。选项代入从最小/最大开始。
  4. 先排除再精算：选项是比例/范围时，先用量级、整除、尾数排除；能估算就不硬算。

高频陷阱

  • 比例题忘记“调动后”的基数变化，直接拿原比例算。
  • 经济利润题把“定价/售价/成本”混用，或忘记打折。
  • 极值题只算“最大”，忽略“还要满足其余条件”。
  • 概率题正面分类漏项，或把“至少”当成“恰好”。

06 · 资料分析：问法 → 公式 → 数据

MODULE 04资料：先认题型，再找数据，最后才计算50 题 · 答案 B17/D18/C9/A6

这个模块的条件是什么

问法决定公式，公式决定要找哪几个数据，数据在材料里的位置决定计算量。三者顺序不能反。

四条不变量

  1. 先判定题型：“占/比重”“同比增量/增长量”“增长率”“平均/倍数”“综合分析”，每一类对应固定公式。
  2. 正确答案是算出来的：不是“看起来合理”的那个。错误选项对应时间错位、基期/现期混用、单位错、比重与增量混用。
  3. 区间选项只估算：选项是“小于5%/5%–10%/…”时，算到能落区间就停，不追求精确。
  4. 综合分析先易后难：先做能直接判定的选项；“逐年/均/超过/不超过”要查边界和例外。

09 · 高分应试策略

会做不等于考得高；考场上的核心是“把时间花在能闭合的题上”。

时间预算（以 100 题 / 120 分钟为例）

12–15政治+常识
28–30言语
28–30判断
25–28资料
10–12数量
5–8涂卡复查

按你实际卷面调整；四川 2026 模块题量以官方大纲为准；原则是“先做能闭合的，数量最后”。

三遍做题法

  1. 第一遍（约 60% 时间）：只做条件能闭合的题；闭合不了就标记，绝不恋战。
  2. 第二遍（约 25%）：处理标记题；用“漏了哪个条件”回题干找区分点。
  3. 第三遍（约 15%）：蒙猜 + 涂卡 + 检查错位；不空题。

蒙猜规则

  1. 先排除到 2 选 1，再猜；不要四选一硬蒙。
  2. 选项分布只做最后校验，不作为主策略。样本答案分布并不均匀：数量 D 只有 5/50，资料 D 有 18/50。
  3. 改答案只在“找到漏掉的条件”时改；凭感觉不要改。

复盘规则

  1. 错题只写一行：我漏了哪个条件？不抄解析。
  2. 按“条件类型”归类，不按题归类：搭配没看、定义漏槽、论证桥没找、公式错、法条例外没记。
  3. 每周回看一次“条件卡”，只看自己漏过的那几类。

训练节奏（考前 4 周）

  1. 每天 20 题限时 + 10 题复盘；限时按模块上限。
  2. 每周 2 套整卷；整卷只记录“超时题”和“漏条件题”。
  3. 考前 2 周不再追新题；只刷错题条件卡 + 资料/言语手感。

最后一句

你不需要在考场上“变得聪明”，你只需要做同一件事：把题干的条件一条条摆出来，选那个全部满足的选项。

言语看三关交集，判断看形式匹配，数量看方程唯一解，资料看公式计算，常识/政治看原文边界。六个模块，一套动作。

配套病例：行测类题对照精讲 · 本页只讲“怎么判”，精讲页讲“这一类为什么错”。
