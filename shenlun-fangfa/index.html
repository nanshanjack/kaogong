申论与公文判定法

从官方公文逻辑 + 申论材料逻辑 + 你的 8 套行政执法卷，归纳同一套动作：定文种 → 定对象 → 摘要点 → 排结构 → 写表达。

申论轨道 行测判定法 → ← 工作台
依据 2026-11-07 考据 公文条例 + GB/T 9704（A 级） 高校课程 + 官方媒体（B+） 你的 32 题评分卡为验证层 四川省考时长以公告为准

申论不是“写作文”，是“从材料里把要点搬出来，按文种结构摆好”。

行测比的是“四个选项里哪个必然对”；申论比的是“材料要点有没有搬全、结构有没有摆对、语言有没有写准”。前者是条件判定，后者是要点重组。两件事共享同一个开头：先定目标，再找依据。

铁律一

先定文种和对象，再动笔。文种决定结构和语气；对象决定称谓和口吻。

铁律二

要点来自材料。材料原句是唯一源头，只做压缩改写，不发明、不抒情。

铁律三

结构按公文走。标题/称谓/正文/落款，该有的一项都不能丢。

01 · 三层证据与双轨衔接

规则不靠“感觉”，按三层处理：官方定范围与文种，课程/媒体给方法，你的评分卡做验证。

① 范围层

申论大纲：阅读理解、综合分析、提出和解决问题、文字表达；公文条例：15 个法定文种与行文规则。

解决“考什么、公文是什么”，不解决“怎么写快”。

② 规则层

高校慕课、官方媒体文章、公文教材：文种选用依据、材料阅读法、讲话稿要素、语言规范。

每条规则写清适用条件与边界。

③ 验证层

你的 8 套行政执法卷 / 32 题 / 134 个答案要点：文种分布、要点来源、结构评分都在评分卡台账里。

与台账冲突的规则，以台账为准。

02 · 大纲四能力 → 五步动作

大纲只说“考什么能力”；本页把四项能力翻译成考场上可执行的五步。

大纲能力考场含义对应动作
阅读理解读懂材料、找准范围第 1–2 步：定文种/对象，带题读材料
综合分析辨清材料逻辑第 3 步：按“问题/原因/对策”摘要点
提出和解决问题对策要能落地第 3–4 步：对策从材料提炼，排进结构
文字表达规范成文第 5 步：按文种结构写，语言准、简、庄
  1. 定文种 / 目的

    题干让你“写什么、为什么写”。文种决定结构，目的决定语气。

    动作：圈出文种词（倡议书/讲话稿/汇报提纲…）和行为词（号召/汇报/动员）。
  2. 定对象 / 场合

    写给谁、在什么场合。决定称谓、口吻、要不要落款。

    动作：找“面向/针对/以××名义”。
  3. 摘要点

    带题回材料，只摘三类：问题、原因、对策（按题干要求取舍）。

    动作：一条要点 = 关键词 + 材料原句压缩，写进草稿不写进答案。
  4. 排结构

    按文种骨架分配要点：开头给背景/目的，主体分条，结尾给要求/呼吁。

    动作：先列一句话提纲，每段一行，再动笔。
  5. 写表达 + 校验

    成文后 20 秒自检：文种、称谓、落款、字数、要点数。

    动作：见第 09 节清单。

03 · 材料怎么读：词—句—段

来自川观新闻的三层读法（B+），与“答案蕴含于材料”同源；这一步决定你能不能搬全要点。

词：重关联

高频词、关联词、转折词就是材料的态度和结构信号。“但是/然而”后面是要点；“应当/需要/建议”后面是对策。

句：抓首尾中

段首句常给观点，段尾句常给结论，段中引用/数据/案例是论据。观点句直接做要点；案例只用来找“它证明了什么”。

段：析逻辑

材料常见逻辑是问题 → 影响 → 原因 → 对策。按这四个筐摘要点，筐名就是你的分类词。

要点改写三招：只压缩，不发明

  1. 换主语：把案例里的“某人/某地”换成题干要求的主体（如“执法部门”）。
  2. 删修饰：去掉形容词、例子、重复语，留下动词+宾语。
  3. 合并同类：同一筐里意思相近的句子并成一条，关键词前置。
  • 发明材料里没有的对策（“加强监管”但材料说的是“公开信息”）——不得分。
  • 整段照抄——字数爆炸，阅卷找不到关键词。
  • 只抄案例数字——数字是论据，要点是它背后的结论。
B+：川观新闻问题→影响→原因→对策 四筐观点句直接做要点

04 · 文种怎么定：法定 vs 事务性

条例 15 文种是“法定公文”（A 级）；申论高频考的是事务性公文（教学共识，C 级，待你的评分卡逐题对照）。

GENRE MAP先分清两套文种体系条例 A 级 · 事务性 C 级

法定 15 文种（条例第八条，A 级）

决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。考场单考法定文种的概率低，多是借它的行文逻辑考事务性文种。

文种选用依据（条例 + 慕课）

  1. 行文目的：要人做→通知/倡议；向上说→报告/汇报；对人讲→讲话稿；求批准→请示/建议。
  2. 发文者身份：题干“以××局/××名义”——身份决定语气与权限，政府机关不用网络流行语。
  3. 主送对象：“面向市民/全体商户/新生家长”——决定称谓与口吻；对象越具体，称谓越具体。

申论高频事务性文种（10 个）

倡议书QUAN全格式

面向公众号召行动。骨架：背景问题 → 分条倡议 → 呼吁。

公开信XIN全格式

面向特定群体说明+动员。骨架：缘由 → 事项 → 希望。

讲话稿 / 发言稿HUA半格式

场合性讲话。骨架：开场（场合+目的）→ 主体分条 → 结尾要求。六要素：讲者/对象/场合/目的/内容/语言。

汇报提纲HUI标题+正文

向上汇报。骨架：成绩 → 问题 → 原因 → 下一步。

工作汇报 / 情况汇报BAO全格式

同汇报提纲，多落款；要点按“做法+成效”配对写。

通知TONG全格式

要对象执行。骨架：依据/目的 → 事项分条 → 执行要求。

报告BG全格式

向上反映情况。骨架：情况 → 问题 → 建议；不夹带请示事项。

意见 / 建议YIJ全格式

给对象提对策。骨架：现状问题 → 分条建议（每条=做法+理由）。

短评 / 时评DUP标题+正文

媒体视角评现象。骨架：现象 → 观点 → 材料论证 → 结论。

经验交流材料JY半格式

介绍做法。骨架：总起（做法一句话）→ 分条经验（做法+效果）→ 结语。

待对照：以上 10 个文种的考频与格式档，需与工作台「采分点台账」里 32 题的实际文种逐题对照；不一致的以台账为准。

05 · 格式三档：先保结构分，再保内容分

格式分是最便宜的分数：结构项缺一项丢一项。先判断档位，再动笔。

档位结构项适用文种阅卷看点
全格式标题 + 称谓 + 正文 + 落款 + 日期倡议书、公开信、通知、报告、意见/建议、工作汇报称谓顶格；落款单位+日期右下；日期写“×年×月×日”
半格式标题 + 称谓 + 正文（无落款）讲话稿、发言稿、经验交流开头要有场合语（“各位代表：”）；结尾有要求/展望
无格式标题 + 正文分条（无称谓/落款）汇报提纲、短评、内容要点类标题即观点或“关于××的提纲”；正文条理>辞藻

标题公式（山西传媒，B 级）

单位 + 事由 + 文种，例如《××市市场监管局关于规范摊贩经营的建议》。考场没给单位就写“关于××的××”；题干说“不必考虑格式”时，把时间还给要点。

  • 把“提纲”写成全文——字数爆炸、结构分没了。
  • 讲话稿写落款——场合性文稿不署名落款。
  • 称谓缺失——有对象却不敢称呼，格式分直接丢。
GB/T 9704 仅法定格式参考三档为教学共识（C）题干要求优先于模板

06 · 结构怎么排：分文种骨架

骨架是“段落功能表”，不是套话；每个空位都从材料里填。

文种开头写什么主体写什么结尾写什么
倡议书 / 公开信背景+问题+目的（为何倡议）分条倡议：每条=做法+一句理由呼吁号召（对象+行动）
讲话稿场合+目的+一句定调分条讲清“做什么/为什么/怎么做”要求或展望
汇报提纲 / 工作汇报总起：工作主题一句成绩（做法+成效）→ 问题 → 原因下一步安排
通知依据/目的一句事项分条：时间、对象、要求执行要求（“请遵照执行”）
意见 / 建议现状与问题一句分条建议：做法+理由/预期效果一句收束（可无）
短评引材料现象观点+两层论证（材料为据）回扣观点一句

要点分配的两条硬规矩

  1. 问什么答什么：题干只要“对策”就别写问题背景超过一行；要素错位是最大丢分。
  2. 字数跟着要点走：先数要点条数，再按条数均摊字数；一条要点≈关键词(4–8字)+一句话(15–30字)。
骨架为教学共识（C）以你的评分卡结构分对照校准

07 · 语言怎么写：三改三不

条例要求“表述准确、文字精练”（A 级）；考场落地就是三改三不。

三改

  1. 换主语：案例主体 → 题干要求的执行主体。
  2. 删修饰：形容词/排比/例子删掉，留动词+宾语。
  3. 并同类：同义句合并，关键词提到句首。

三不

  • 不发明：材料没有的对策、数据、意义。
  • 不抒情：公文不用感叹号轰炸和排比堆砌。
  • 不口语：不用“我觉得”“特别棒”；用“应当/建议/已/将”。
压缩示例 · 只演示改写方向 材料句：“执法人员经常在夜市巡查到深夜，非常辛苦，但占道经营还是屡禁不止，老百姓意见很大。”
要点写法：问题：占道经营屡禁不止（执法投入大、效果差，群众不满）。——关键词前置，修饰删净。
语言四要求：准确/简洁/庄重/规范（B）关键词前置

08 · 应试节奏与卷面

四川省考申论时长以公告为准；下面按比例给节奏，任何总时长都能换算。

时间按比例切

审题 10%：文种/对象/范围/字数 四定 读材料 40%：带题划“问题/原因/对策” 提纲 10%：每段一行 成文 35%：先关键词后成句 校验 5%：清单过一遍

小题先做（要点好搬、分数稳），大作文留足 35% 以上时间；材料只读一遍半：第一遍通读划线，第二遍只回题干相关段。

卷面三条

  1. 分条清晰：一条一行起步，关键词写在句首。
  2. 不涂改：写错画一条斜线，不糊团。
  3. 顶格与空格按档位：称谓顶格、正文首行空两格、落款右下。
节奏比总时长重要：审题不超 10%，读材料不超过一半时间。

09 · 成文前 20 秒自检

交卷前把这张清单过一遍，每一项都是白给的分数。

  • 文种对吗：写的结构是题干要的文种，不是我最熟的模板。
  • 对象对吗：称谓、口吻、身份与题干一致。
  • 格式对吗：全格式/半格式/无格式，档位没拿错。
  • 要素全吗：题干要的问题/原因/对策，筐筐有货。
  • 要点来自材料吗：每条都能指回材料某句，没有发明项。
  • 结构合吗：开头—主体—结尾的功能没有错位。
  • 字数超吗：按格子数过，留有余量。

最后一句

申论的全部秘密就一句：要点从材料来，结构从文种来，语言从规范来。三样都对，分数就在那里。
